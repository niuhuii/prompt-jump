# prompt-jump

[English](README.md)

**在很長的 Claude Code 對話裡，直接跳回你之前問過的任何一則，不用一直往上捲。**

提示框上方每一則提問一根刻度，整段對話一眼看完。滑鼠指到某根刻度，就預覽那一則和回答的開頭；點一下，或打 `/jump 3`、`/prev`、`/next`，對話就捲回那裡。

```text
❯ 最後再檢查一次手機版
● Update(src\layout\Footer.tsx)
  Ran 2 shell commands
● 手機版三個主要頁面都正常，只剩頁尾字太小，已調大
 9/12  ▄ ▅ ▄ ▅ ▄ ▄ ▅ ▃ ▄ ▅ ▄ ▄                                 k: ‹  j: ›  a: 回答  l: 清單
 3  為什麼重新整理後又被登出   因為 token 過期後沒有換新的 token：refresh 的回應被當成…
❯
```

第一列：目前在第幾則（`9/12`）、每則一根刻度、四個按鈕。那一輪做的事越多刻度越高，有工具呼叫失敗的那輪是紅色，目前位置是青色。第二列是預覽：滑鼠指到哪一則就顯示哪一則（這裡是第 3 則），沒指的時候顯示目前那一則。

## 安裝

在 Claude Code 終端機的提示框輸入：

```
/plugin install prompt-jump --marketplace niuhuii/prompt-jump
```

問要不要加入 marketplace 時按 `y`，再按 Enter 裝給自己（所有對話都會有）。接著會出現設定畫面，用預設值就可以。

或在 shell 裡：

```
claude plugin install prompt-jump --marketplace niuhuii/prompt-jump
```

**要能跳回去，請開全螢幕版面**（原因見[已知限制](#已知限制)），三種方法擇一：

| 方法 | 效果 |
| --- | --- |
| `/tui fullscreen` | 馬上切換；Claude Code 會重開並接回這段對話 |
| 在 `settings.json` 加 `"tui": "fullscreen"` | 之後每次開都是全螢幕版面 |
| `CLAUDE_CODE_NO_FLICKER=1 claude` | 只影響這次啟動。透過 SSH 連進 Windows、在 `tmux -CC` 裡時，Claude Code 會自動改用一般版面，這時只有這個方法有效 |

在 Claude Code 裡打 `/jump-help` 也看得到這張表。

同一個 repo 另有一個可選的外掛 [compact-edits](#compact-edits選用)，要另外裝。

## 功能

- **提示框上方的刻度列。** 你打的每一則一根刻度，依序排；兩則之間停超過 15 分鐘就空一格。高度是那一輪的工作量（改了幾個檔、跑了幾個指令、回答多長），紅色是那輪有工具呼叫失敗，青色是目前位置。不是你打的（背景工作通知、斜線指令）不列；外掛載入前就在對話裡的訊息（例如 `--resume` 之後）一載入就有。刻度放不下時只畫目前位置附近一段，左右標還有幾則（`‹24`、`23›`）。
- **預覽。** 滑鼠指到刻度，或用鍵盤移到刻度，第二列就換成那一則的提問和回答開頭。
- **跳回去。** 點刻度，或用 `k`／`j`（上一則／下一則）、`a`（最後一個回答的開頭），對話就捲到那一則在最上面。
- **清單。** 按 `l` 或打 `/jump` 打開完整清單：一則一列，編號、提問，右邊是短標記：`±2` 改了幾個檔、`$4` 跑了幾個指令、`✗1` 幾個失敗。目前那一則有色條、底色、粗體。滑鼠指到某一列，會浮出一張卡片：提問、回答開頭、那一輪做了什麼。卡片放在清單底下；清單比窗格長時，放在窗格離你指的那一列較遠的一端，不會蓋住那一列和上下相鄰的列，滑鼠可以一列一列往下掃。時間只出現在停頓分段的那條線上（`── 10:05  停 20 分 ───`），不在每一列。
- **搜尋提問、回答和檔名。** 清單的篩選框和 `/jump 關鍵字` 會比對提問、那一輪回答的開頭、那一輪改過的檔名，所以 `/jump tiles.tsx` 會找到改過那個檔的那一輪。某一列符合的地方在畫面上看不到時，下面一行灰字寫出原因：`檔名 tiles.tsx`、`回答：…token 過期…`，或提問裡被截掉的那一段。
- **書籤。** `/mark 名稱` 記下畫面最上方的位置；`/jump @名稱` 跳回來。
- **繁體中文與英文**，跟著你的設定。

上面這些都直接從對話紀錄數出來，不呼叫模型（下面選用的自動標題除外）。

## 指令

| 指令 | 做什麼 |
| --- | --- |
| `/jump` | 打開清單 |
| `/jump 12` · `/jump -1` | 跳到第 12 則 · 最後一則 |
| `/jump 登入頁` · `/jump tiles.tsx` | 跳到提問、回答或改過的檔名符合的那一則；符合好幾則時，提示框上方出現選單，每一則都寫出為什麼符合 |
| `/prev` · `/next` | 上一則／下一則（也可以 `/jump prev`、`/jump next`） |
| `/ans` | 最後一個回答的開頭 |
| `/mark [名稱]` · `/jump @名稱` | 把目前位置記成書籤 · 跳回去 |
| `/marks` · `/unmark 名稱` | 列出書籤（附選單）· 刪掉一個 |
| `/jump-help` | 為什麼一般版面捲不動、怎麼開全螢幕版面 |

打 `/jump 關鍵字` 的時候，符合的訊息會出現在自動完成裡；按 Tab 帶入編號。

用鍵盤操作刻度列：按 `ctrl+x tab` 移過去，方向鍵和 Tab 在刻度之間移動（預覽跟著換），Enter 跳過去，字母按按鈕：`k` 上一則、`j` 下一則、`a` 回答、`l` 清單。`Esc` 回到提示框。

## 設定

安裝時的設定畫面就能設，之後在 `/config` 改。

| 設定 | 預設 | 做什麼 |
| --- | --- | --- |
| `autoOpenPane` | **關**（0.3.0 以前是開） | 每次開始對話就在旁邊打開清單。關：刻度列一直都在，要清單時按 `l` 或打 `/jump`。 |
| `language` | `auto` | `auto`、`zh-TW` 或 `en`。`auto` 依 Claude Code 的 `language` 設定、再依系統語言，都判斷不出時用英文。 |
| `titles` | **關** | 自動標題，見下面。 |
| `titleModel` | `haiku` | 自動標題用的模型。 |

### 自動標題（預設關）

打開 `titles` 後，每輪結束時外掛會請模型替那一則寫一行標題，清單裡用標題取代原本的提問。

- **會送出什麼：** 你的提問與回答開頭（各約 300 字），以及那一輪改過的檔名，經由你自己的 Claude Code session 送出。
- **花費：** 每輪多一次模型呼叫，算進你的用量。清單最下面會顯示估計用了多少 token。
- **不會送出**的情況：session 有資料規則（例如零資料保留）、非互動執行（`claude -p`）、被中斷的那一輪。
- 關著的時候什麼都不送，清單顯示你原本打的字。

## 已知限制

- **只有全螢幕版面捲得回去，刻度列也只在全螢幕版面出現。** 一般版面（常是預設）的對話在終端機自己的捲動區，任何外掛都捲不動，外掛也沒辦法替你切換版面。一般版面裡清單和指令照樣能用：`/jump 3` 會印出那一則的全文並說明為什麼捲不過去；第一次遇到時，回覆後面會附上怎麼開全螢幕版面（只附一次，`/jump-help` 隨時再看）。
- **一般版面沒有滑鼠。** Claude Code 在一般版面不把滑鼠交給外掛；清單請用 `ctrl+x tab` 和鍵盤操作。
- **不能註冊全域快捷鍵。** 外掛沒辦法新增自己的快捷鍵。請用指令，或按 `ctrl+x tab` 再按字母。
- **最後幾則**下面沒有東西可以捲，跳過去時到不了畫面最上方，會出現在畫面下半；在那裡按 `k` 可能不會動。
- **書籤**跳回的是當時畫面最上方那個回答區塊的開頭，不是同一行。書籤只在這次 session 有效。
- **終端機很窄時**，刻度列在任何寬度都能用。清單要約 110 欄以上才放得到對話旁邊；更窄時按 `l` 或打 `/jump` 會開成提示框上方的一個框，框裡指到某一列時，改成一行的小卡片（編號＋回答開頭），一樣不蓋住相鄰的列。
- **時間、停頓和預覽**：時間和 15 分鐘分段只知道外掛在跑的時候送出的那幾則。搜尋和預覽用每則回答的前 300 字。
- **工作量**只數主對話；子代理裡做的事不算。
- 在終端機以 Claude Code 2.1.332 開發與測試。桌面版 App 和 IDE 外掛沒有檢查過。

這是在解 Claude Code issue [#63901](https://github.com/anthropics/claude-code/issues/63901)（在目前對話跳到先前的使用者訊息），官方關成 not planned。

## compact-edits（選用）

同一個 repo 裡的另一個外掛。裝了之後，Edit／Write／MultiEdit 的結果縮成一行，例如 `改了 tiles.tsx +12 −3`；按 `ctrl+o`（完整紀錄）仍看得到完整對照。

```
/plugin install compact-edits --marketplace niuhuii/prompt-jump
```

唯一的設定是 `language`（`auto`、`zh-TW`、`en`）。

## 移除

```
/plugin uninstall prompt-jump
/plugin uninstall compact-edits
```

## 開發

```
claude plugin validate plugins/prompt-jump      # 檢查 manifest 與 hooks module
claude plugin test plugins/prompt-jump          # 跑 tests/ 裡的測試
claude --plugin-dir plugins/prompt-jump         # 在一個 session 裡試這份
```

`--plugin-dir` 只在那個 session 取代已安裝的同名外掛。各版改了什麼見 [CHANGELOG.md](CHANGELOG.md)。
